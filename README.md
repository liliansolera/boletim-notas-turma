# 📚 Gerenciador de Notas de Turma

## 💡 O que esse projeto faz

Permite cadastrar alunos e suas respectivas notas, calcular médias individuais e identificar automaticamente o aluno com a **maior** e a **menor** média da turma.

Funcionalidades:
- Adicionar alunos e notas
- Remover alunos da lista
- Calcular a média de cada aluno
- Exibir o destaque positivo e o que precisa de mais atenção

---

## 🛠️ Pré-requisitos

Apenas **Python 3** instalado na máquina. Nenhuma biblioteca externa necessária.

- [Download Python](https://www.python.org/downloads/)

---

## ▶️ Como rodar

No terminal, na pasta do projeto:

```bash
python notas_turma.py
```
